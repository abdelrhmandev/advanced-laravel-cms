# 🚀 Laravel Modular CMS

A powerful modular CMS built with Laravel & Livewire, designed for scalability, flexibility, and multi-language support.

---

## ✨ Features

- 🔥 Dynamic Blocks System (like WordPress builder)
- 🌍 Multi-language support
- 🧩 Modular architecture
- ⚡ Performance optimized (caching)
- 🔐 Role & Permission system (Spatie)
- 📊 Admin dashboard
- 📦 RESTful APIs ready

---

## 🛠 Tech Stack

- Laravel
- Livewire
- MySQL
- Alpine.js
- Bootstrap / Tailwind
- Spatie Permissions

```bash

cd laravel-modular-cms
composer install
cp .env.example .env
php artisan key:generate

npm install && npm run dev
